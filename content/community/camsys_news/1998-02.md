{{begin-newsitem |date=1998-02-17 |title=Uploading Funcraft |author=King Arthur |site=Camsys |categories=Camsys}}
Uploading Funcraft today... should be done by midday or afternoon. The download's a little more complicated this time. As it was so difficult for me to get it uploaded in one piece, I sent it up in 1.44 meg chunks, and put each file up in its own directory. You'll have to download each file seperately, and then save each file to a disk, where you can finally unzip the thing. Believe me, I'd like to put it all in one file, but right now with my slow connection speed, it's just not possible. Besides, if it gets stuck downloading, it's easier to try redownloading a 1.4 meg file rather than a 4.5meg file, right? I mean, come on, no complaints! It's FREE!

{{begin-newsitem |date=1998-02-16 |title=SPUD Farmer info |author=King Arthur |site=Camsys |categories=Camsys}}
What does it do, you ask? Well, in short, it provides you with the ability to add extra players into the game. And do a few other interesting things in the process. I'll have a tutorial up in a few days time for you to use with it. To get you going for now, make sure you use an already made map file, and that you have units designated in there that you want to convert to other player's units and start locations. Just select the unit you desire, check its coordinates, and change it to whatever you want! Have fun!
{{end-newsitem}}
