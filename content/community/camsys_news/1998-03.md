{{begin-newsitem |date=1998-03-25 |title=SPUD Farmer Save code progress |author=King Arthur |site=Camsys |categories=Camsys}}
[King Arthur](mailto:king_arthur@rtshq.com) is now working on the Save code for [SPUD Farmer](software.htm). It should be completed sometime this weekend most likely. Beta testers should try to finish bug-testing the current BETA by Saturday, when I expect to releaseBeta 5, which will include the Save code. Beta 6 will include a minimap representation of the actual PUD, and will support the lack of optional sections in the PUDs like the UDTA, UGRD, and ALOW sections. SPUD Farmer currentlyrequires that UGRD and UDTA sections be present in order to read the PUD properly. ALOW, however, is optional. SPUD Creation should also be completed for BETA 6, as will support for external files for the UGRD, UDTA, and ALOW sections.
{{end-newsitem}}
