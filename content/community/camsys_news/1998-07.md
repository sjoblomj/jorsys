{{begin-newsitem |time=1998-07-22T23:53:00Z |title=PalConverter 1.0 Uploaded |author=King Arthur |site=Camsys |categories=Camsys}}
The other day I sat down and decided to start messing with Palette files, in hopes of correcting the various StarCraft palettes out there that were all converting GRP files to strange-looking colors... Unfortunately, I didn't have a graphical interface to do this. However, I did remember that Paintshop Pro and Paintbrush both have fairly decent Palette Editing methods... so I got to thinking... maybe I should create a utility that converts palette formats. And that's what I ended up doing... :) PalConverter 1.0 is probably the simplest program to use, and shortest SC program I have done yet (actually, the only SC program). There's almost nothing more to this program than common dialog boxes and 3 radio boxes for you to select the format of the palettes... that's it. Simple stuff, really. Anyways, it supports **6** different types of conversions:

* JASC (Paintshop Pro) Palette Files-StarCraft Palette Files
* Microsoft Palette Files-StarCraft Palette Files
* JASC (Paintshop Pro) Palette Files-Microsoft Palette Files
* Microsoft Palette Files-JASC (Paintshop Pro) Palette Files
* StarCraft Palette Files-JASC (Paintshop Pro) Palette Files
* StarCraft Palette Files-Microsoft Palette Files

If I've left out any important palette formats, be sure to let me know. Actually, drop me an email [here](mailto:KingArthur@warzone.com?subject=Palettes) and attatch the Palette file to the email. Enjoy!

* [Download PalConverter 1.0 (With MSVB 5.0 System Files)](software/palconverter1.zip) - 1.5Mb
* [Download PalConverter 1.0 (Program Only)](software/palconverter2.zip) - 12Kb
{{end-newsitem}}


{{begin-newsitem |time=1998-07-19T17:57:00Z |title=StarCraft GRP (Unit Graphics) Specs uploaded. |author=King Arthur |site=Camsys |categories=Camsys}}
My apologies to Klint. I forgot to upload his GFX specs sheet. You can now see it [here](SCUMFORM/GFXForm.htm). A note about GFX... GFX and GRP files are identical in format. So what he's outlined in his specs sheet applies to both WarCraft GFX files and StarCraft GRP files. You can decompress/convert extracted GRP files into bitmaps using WarDraft's Graphics Converter and the proper palette file. (Which I do not have, unfortunately).
