{{begin-newsitem |time=1999-01-28T03:49:00Z |title=Arsenal II News |author=King Arthur |site=Camsys |categories=Camsys}}
Just in case anyone cares, I discovered the meaning of the "Group" variable on the "AI/Orders" page of the Units editor in Arsenal II - it corresponds to the number of a technology required in order for the AI/Order to be carried out. A value of 44 signifies that no technology is required. Any other value corresponds to the technologies in the order they are listed in the technology editor. A new release of Arsenal II will add a listbox for this item so that you don't have to guess on the number required here.

{{begin-newsitem |time=1999-01-24T23:17:00Z |title=Commands and a possible editor |author=King Arthur |site=Camsys |categories=Camsys}}
All day yesterday and today I've been studying the command structure for StarCraft - stuff embedded in the StarCraft exe file. I've made lots of notes, and Merlin thinks that we have enough to start work on a command editor which will create files that you would place in a CWAD and then patch the EXE while it's running (so you don't make permanent changes to it). I was able to successfully make the Marine for instance into a Transport this morning - previous patches with CWAD's had allowed the marine to pick up but never release any units. By changing the commands anr other stats I was able to make the marine act like the Dropship, etc. Basically this means that soon you will be able to edit pretty much everything outside of AI scripts and Image scripts (which I'm also working on in hopes of a future editor for them).

{{begin-newsitem |time=1999-01-22T01:45:00Z |title=NEW StarDraft/Arsenal II/StatPrinter UPLOADED! |author=King Arthur |site=Camsys |categories=Camsys}}
After extensive in-house beta testing, we have decided to release what should be the last major version of StarDraft/Arsenal II/StatPrinter that you will likely see. That doesn't include updates for bug fixes and StarCraft version changes. Basically what it means is this is the last version of StarDraft/Arsenal II/StatPrinter that we will probably completely overhaul and add lots of new features.

New to this version:

* First and foremost: Arsenal II has been tested thoroughly and should now be bug-free. All previously caught bugs have been fixed, so you should be able to run Arsenal II without having to worry about it corrupting your data files/changes.
* Should Arsenal II have any remaining bugs, you can now decide whether or not you want to save the changes that you made during your Arsenal II session when you shut down Arsenal II. Yipee! :) Sorry it took so long on this one :)
* One word: StatPrinter. The new version in my opinion (and several other people including Shlonglor) just plain rocks. There are so many cool new features and fixes that you'd swear this was re-started from scratch (it practically was).
* StatPrinter now supports grouping by race, unit, building, etc. It also supports hiding Sub-units (so that the Goliaths and Tanks have proper attack stats) as well as custom names for your units (which you can change by editing the "arsenal\unit_list.txt" file in your CWAD
* Arsenal II has several new listboxes, a modified and less crowded layout, and a brand new help system which explains what everything that we know about does in Arsenal II.
* TBLEdit will now save changes made to your TBL files. The previous version had a saving problem which has now been fixed.
* The InstallShield version has been fixed so that the StarDraft icon no longer points to ploader.exe but instead to Stardraft.exe
