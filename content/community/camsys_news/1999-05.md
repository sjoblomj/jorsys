{{begin-newsitem |time=1999-05-29T03:13:00Z |title=Incredible News |author=King Arthur |site=Camsys |categories=Camsys}}

{{begin-newsitem |time=1999-05-22T04:52:00Z |title=Map Generator Clarification |author=King Arthur |site=Camsys |categories=Camsys}}
I feel a clarification of my post is necessary after Deathwing of Infoceptor posted about it and seemed to have mis-interpreted what I said yesterday. The minimap generator, one of several components of the program in question, still operates as before, generating small bitmap/gif/jpg images of around 18kb in size. The map generator, a brand new component, generates bitmap images of up to 64mb in size, simply because it's drawing an actual-size picture of the entire map. The Tileset Export component which saves a picture of all the tiles in a tileset generates bitmap files of approximately 8mb in size.

In other words, unlike what Deathwing presumed, I'm not forcing the minimaps that you were able to generate before into large real-size images that require 64mb of hard drive space apiece. The minimap images are still quite small and manageable for a website or hard drive of any size.

The map generator component that I introduced in the latest version is just an additonal tool available to webmasters who wish to try and generate maps that can resemble the images in Blizzard's StarCraft Compendium without much trouble.

I apologize for any confusion that yesterday's post may have inadvertantly caused; what Deathwing implied in his post is simply untrue, and he refused to post a correction when I requested one.
{{end-newsitem}}


{{begin-newsitem |time=1999-05-20T23:42:00Z |title=Map Generator Update |author=King Arthur |site=Camsys |categories=Camsys}}
I've just finished up updating the Map Generator (formerly the Minimap Generator) with several bug fixes and adding several features, including support for generating pictures of the entire map, and for selecting a directory to place output files into. Right now, unfortunately, Doodads, Resources, and Units do not show up on either the minimap or map images. Hopefully I will be able to get them to display sometime soon. The main bugfix is one which allows you to place the minidat.mpq archive in the same directory as the TileEdit.exe file. Before it was required that you moved it into the StarCraft directory for it to work, contrary to what my documentation said.

Also note: for anyone downloading the bugfix, you will notice a non-fatal error message upon starting up TileEdit for the first time after you download the new version. This error message can be safely ignored, and will not appear again. There is no need to report it to me. The cause is simply the fact that the program is looking for new registry entries that won't exist until you exit the program again.

Please note that the map generation process is very complex, and requires a lot of your computer's resources. Because the files it generates are stored entirely on the hard drive (and never in RAM), large amounts of RAM are not required. A fast processor is of course reccommended, unless you want to stop all other activities while the map generation is taking place. For maps that are 256x256 in size, the approximate file size for the image generated is 64mb (that's because it is generated as a BMP). Automatic conversion to JPG or GIF format is not possible at this point, but hopefully I will be able to fix that shortly. Please note that the 64mb file size is generally reduced to 8mb when saving to JPG format, and that the 64mb file size is the maximum file size you will get, other map sizes require considerably less disk space. Nonetheless, watch your hard drive space carefully.

{{begin-newsitem |time=1999-05-10T05:45:00Z |title=Minimap Generator Complete! |author=King Arthur |site=Camsys |categories=Camsys}}
I'm pleased to announce the completion of the Minimap Generator.
