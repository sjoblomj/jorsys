{{begin-newsitem |time=1999-10-28T05:10:00Z |title=Arsenal III Released! |author=King Arthur |site=Camsys |categories=Camsys}}
Well all the Beta Testers have been offline for several hours now, so by the time I had all the bugs fixed I had nobody left to send it to :) But I ran it through the checklist I had of the bugs we had found, and all of them seem to have been fixed. As such I've deemed Arsenal III ready for public consumption. This is in no way the final version of Arsenal III - in fact as I stated earlier, only the Unit Editor is functional (the others should be a cinch now that the Unit Editor is working). You'll also notice that there is no artwork yet. That's because I just gave Joel that task tonight :) Unlike our previous software, this new program should be much easier to update on your part - once it's complete you shouldn't have to download the entire file again if bugfixes are necessary - since I've broken up the interface from the file reading, you should only have to download updates to one part or the other.

You'll also notice that the stats loaded aren't from BrooDat.mpq, they are from a file in the "arr" subdirectory of wherever you installed Arsenal III. Initially loading the data from there will be an option once the program is finished, I will let you choose whether to always load from the MPQ or from the hard drive (that way if you want to always load some default stats that are not present in the MPQ you can do so). Also, I intend to add support for editing all the DAT related strings into Arsenal III to simplify that even more. My ultimate goal is to make the interface resemble as closely as possible that of StarEdit without sacrificing the power that previous versions of Arsenal III have had.

In any case, you're probably all clamoring to get your hands on it (as I would guess from the results of the poll):

{{begin-newsitem |time=1999-10-25T03:26:00Z |title=Arsenal II Update |author=King Arthur |site=Camsys |categories=Camsys}}
Seeing as how a large percentage of you (who voted, at least) are still interested in StarCraft software, I thought I would inform you of my work on the new Arsenal II. I started from scratch. I didn't want to try and weed out bugs from the older version that had a lot of unnecessary code making it very difficult to find what you wanted...  In any case, the interface will be completely revamped, in an attempt by me to make it more closely resemble StarEdit's interface (for the Unit Editor, at least). Hopefully this should lead to an easier editing experience since those of you familiar with StarEdit should be able to make a smooth transition. Also for simplicity's sake, I have moved the Weapons/Orders editing into two seperate editors of their own. I think that having them as part of the unit editor caused a lot of unecessary confusion because people thought they had to edit stuff that they didn't really have to sometimes. Plus if you just wanted to edit weapons, it's easier this way. I think having it integrated was a hold-over from the original SCUnit, and seperating it returns it to the way Arsenal used to have it. I'm about 50% done with the Unit Editor. I still have to add loading/saving code, but it shouldn't be too much longer on that. I think I will release the new Arsenal II when the Unit Editor is complete, get everyone's opinions on it, and then proceed from there on the rest of the editors.
{{end-newsitem}}
