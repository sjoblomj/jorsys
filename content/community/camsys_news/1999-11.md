{{begin-newsitem |time=1999-11-29T22:33:00Z |title=Well, Not All The News is Bad... |author=KramerBoy |site=Camsys |categories=Camsys}}
Finally some good news to offset the problems that KA has been facing... The ICE Beta is now officially released (FINALLY!!!).  Though I know that it's long overdue, and that I should have done a much better job with all the time I've had, I am glad that it's finally out.  The program is about 80% completed on the basics, so I figured now is as good a time as any to give it to you guys to test.

For those of you who don't know, ICE is a program that edits iscript.bin - the file which stores the scripts that control StarCraft animations.  It is very powerful in the hands of a skilled user, though only those with extensive knowledge of HEX editing have been able to truly customize it... Until now =).  With the current ICE build, you can completely manipulate the headers and opcodes that the file uses, all using a very simple and effective interface.  ICE Beta includes full CWAD support, which eliminates the need to import and export files that you want to edit, and makes for a very convienient editing process....  Is it just me or does this sound like a really corny commercial? =)

Make sure to download the ReadMe/Demo file.  I would have added it to the installer if I had remembered.  And READ THE README!  It's really important that you follow the instructions it has in there, so that I can get ICE out of its Beta stages as quickly as possible.

The demo CWAD that I included is basically a brief demonstration of ICE's abilities.  At first I had something much more elaborate, but after playing it a few minutes, I realized that it wasn't all that fun to use.  So, instead, I made a MOD that can really be played.  All I did was make a few changes to iscript.bin, so that none of the blood animations disappear.  Ya know when a Marine dies, and it leaves that little blood mark on the ground that slowly fades?  Well, now it doesn't fade.  Makes for some really messy maps, and it just looks plain cool =).  Also, the Siege Tank might Siege up a little strangely;  I can't remember if I took that out =).

Now, on to the downloads:

{{begin-newsitem |time=1999-11-22T05:30:00Z |title=StarCraft Tileset Editor Completed |author=King Arthur |site=Camsys |categories=Camsys}}
A year ago I would have laughed at anyone who said I could pull off a Tileset Editor (meaning I thought it was impossible). Oops the joke is on me :) I'm very happy to announce that there's finally a (partial) Tileset Editor for StarCraft. As I get more time I will be adding features to it (such as Zoom levels, Gamma Correction, Graphical Editing, etc). I suggest that you read the documentation that is provided before you attempt to use it. I think that a lot of you will probably be lost until Ace writes up a tutorial for it (which I have asked him to hold off on until I get more features completed). For anyone who ever used the Tileset Editor that came with WarDraft, the use is somewhat similar. Or at least it is eventually intended to be :)

Two important notes: The Tileset Editor was made part of Arsenal III (so it's not an independent program, although I guess if you really wanted me to I could make it one). Also the Editor only works with the extracted Tileset Data files, which means that you have to extract them from the MPQ's yourself, and it neither writes to nor reads from bitmap/ini files as I had originally intended. The reason was that it was generating huge bitmaps and inis (several megs at least) which is pretty unreasonable. So I've just got it working directly with the data files. You should be able to import/export individual tile graphics in the next version. For now you can manipulate the existing tiles.
