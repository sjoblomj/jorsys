{{begin-newsitem |time=2000-01-31T22:15:00Z |title=ICE |author=KramerBoy |site=Camsys |categories=Camsys}}
Well, since none of you are complaining to me about bug reports/requesting new features, I'll assume that this ICE version satisfied everyone's needs pretty well.  That being said, I think I'll officially make the existing build the final version of ICE in its current form.

Don't fret though; I haven't abandoned the project.  In fact, I'm doing just the opposite.  I've begun work on a brand new, completely rebuilt ICE.  This one will suppport FULL scripting capabilities, IE you'll now *write* code that controls animations, instead of manipulating it in the traditional 'box and button' manner.  I understand that this may be a bit of a challenge for users who don't have any programming experience, and I'm going to do everything in my power to make the program easy to learn.  ICE's language will be based off of C, so anyone with any amount of experience in C programming will be able to pick up on ICE's code very quickly.

The new ICE will be a MUCH more potent editing tool than it is currently, and I hope you'll all be just as happy with it as I assume you are with ICE now (I haven't heard any complaints =]).  Be on the lookout for a brand new ICE in the comming weeks!
{{end-newsitem}}

{{begin-newsitem |time=2000-01-07T17:00:00Z |title=TileEdit update time. |author=Nossirahdrof |site=Camsys |categories=Camsys}}
Well, after sitting on it for a few days I've finally decided to actually release a new version of TileEdit. It adds a few new features that I hope will be useful to everyone. Hopefully this version will be bug free and not need an update, but the additions in this version are tiny compared to the importing/exporting/optimization that was added in the last release, so hopefully there won't be any bugs. Here is a list of the new features, just off the top of my head:

* Added 'Make Blank' button to make MegaTiles truly blank, not just black Tiles.
* Added 'Apply Type To All' buttons to allow for quick changing of all 'types' in a MegaTile, or in all MegaTiles
* Added feature to edit Doodad Placeability. (be sure to go through the readme.txt for an explanation)
* Added different names for Tile Groups to quickly identify Blank Groups, Main Groups, Edge Groups, and Doodad Groups.
* Added palette saving in either .pal or .wpe palette files.
* Labeled Unknowns by what they are believed to do for quick reference. (saves from opening readme.txt all the time.)

Well that's about it. Remember to read the README.TXT file so you know how to use everything and what values you should use for what. [Feedback](mailto:nossirahdrof@yahoo.com) and bug reports are welcome. So here is the download. And to take a page out of King Arthur's book, I'll let you know the build number. :-)
