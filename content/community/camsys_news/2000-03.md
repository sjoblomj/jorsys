{{begin-newsitem |time=2000-03-31T10:16:04Z |title=Tiny AZ Update |author=DI |site=Camsys |categories=Camsys}}
I realized that it would probably be a pain for most people to make the dat formate files for themselves since not everyone knows a lot of scripting (perl is useful :), so I've made 'skeletal' versions of all of them to add to Arsenal 0. Right now, the ones for units.dat, images.dat, sprites.dat, upgrades.dat, and flingy.dat are complete, the others just need an entry list (they all just have 'dummy' entries right now). I leave the rest up to someone who is motivated enough to copy the list out of Arsenal III if need be. :) Or when I have more time, but the ones I've finished already should be enough because I think Arsenal III will handle the rest correctly. Download the entire thing again [here](https://web.archive.org/web/20000818043445/http://www.camsys.org/cgi/download.cgi?id=az) or just download the format files [here](https://web.archive.org/web/20000818043445/ftp://ftp.camsys.org/pub2/CamelotSystems/software/StarCraft/azformats.zip).

BTW, comments are welcome. I know its not all that user friendly right now, but I'm not much of a GUI kind of guy (90% of my time is infront of a UNIX terminal :P). But if people are interested enough it would be pretty simple to make a better UI just from reading in the text files generated (or better yet, someone else could do it :). The main thing I thought this would be useful for is adding entries to a dat file anyway (when/if that becomes possible).

{{begin-newsitem |time=2000-03-30T22:04:14Z |title=Arsenal ZERO! |author=DI |site=Camsys |categories=Camsys}}
Heya. Its me aka Magnus aka DI aka... :) Anyway, I've just followed the recent bandwagon of recruits here at CS. But I've also got a little program I've been working on for the last 2 days (hence the title). While the name may change (I didn't ask KA yet :) the premise is what you expect, its a dat file editing program, though it is not like any of the other Arsenals. First of all, it is not intended for users who need something easy or simple to use; instead it is intended for advanced users who really *really* need a stable version of Arsenal to edit your .dats. Basically, the program takes *your* dat specifications and then generates an ini-like text file from a dat that is easy to edit. And then it can recompile it into a dat. Anyway, see the docs I included for more info.

Right now I've only included a format file for units.dat and am relying on others to help me write format files for the other dats (that's yiou! :). Its really just busy work, nothing difficult. Also, I've included source code in the event that someone would like to make a Mac port or something (its command-line right now)... or in the possibly (hopefully unlikely) event that there are bugs and I don't have time to fix them at the moment. Anyway, enjoy.

[Download Arsenal 0 v 1.0](https://web.archive.org/web/20000818043445/http://www.camsys.org/cgi/download.cgi?id=az)
{{end-newsitem}}
