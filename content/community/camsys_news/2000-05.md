I must say this 4-days weekend I had was fairly productive. Well, first of all, if you haven't noticed the 100+ responses in KB's post below, most of them have been written in 4 days, so it's not only me who has been productive ;) If you feel scared in front of this armada of texts(I understand you), just know that KB paid his punishment for proclaming itself Czar, so the peace is finally restored at Camelot. As for "serious" stuff, I've been working on ScAIEdit III too. Although I've been busy with Real Life(tm) for 2 days in that long week-end, I still had some time to work on it for the 2 days remaining :) So, I guess you want to know what I've accomplished so far...

First, I've got the ASC3 scheme completed, now I have a clear idea of how they will be designed. There will be many similarities with the previous versions, but the command assignment will be more close to the real thing, opcodes and parameters. For example, instead of writing 'marine = 2' as you could do in the 2 first versions of ASC files, ASC3 replaces this with 'train 2 marine'. Not a big deal you might think, but this brings more power to ASC files, as all the opcodes will be supported that way. Another new interesting feature will be macros. You'll be able to put some ASC code in a text file, and recall it using the macro name you want. Cool, eh? :) A nice example is for those who already know AI scripting : You know these 'Set General Command Target' you have to put after built units? Well using a macro, you could put both of these call only writing this '!build 1 scv' and the macro will put the 'build' and 'set_gencmd' call automatically on the compilation. The '!' tells ScAIEdit III that you're calling a macro, in this example named 'build'(no link with the actual real command). In fact, I'll include it on the release. **Don't worry** if you don't understand anything I've just said, all will be so clear once you'll have it in your eyes :) Why do I feel I'm like explaining a crazy scientific theory no one understands? ;) Perhaps it's because my explanation is a bit dark. Anyways...

After designing ASC3 files, I've written the **AI->ASC3** converter, and it's actually working really good :) Maybe some tweaks will be needed, but the generated code is actually near perfection and working. Now **ASC3->AI** will be more difficult, as the program will have to check the ASC3 syntax, report mistakes, and all. But I've already started on this, and with some luck I should get through it quickly. Once this is done, 'Script Compiling' will be the next important feature to add. After that, it will be test time to see if StarCraft likes the generated AI file :) After this step, things will be lots more interesting, as I'll work on extra stuff, leading eventually to the beta and public release. No, I'm not pointing any release date as long as I don't feel I have things under control, sorry.

To give you an idea of the newest window called 'AI Script Code Editor', I have posted a new screenshot on the link below. It shows the ASC3 file of the AI Script 'Terran 11 - Zerg Town' generated by ScAIEdit III. Notice the seperations the generator made, so the code is easier to read. I had fun writing ScAIEdit III code, as you can see :)
