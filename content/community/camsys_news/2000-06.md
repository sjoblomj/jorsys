{{begin-newsitem |time=2000-06-10T01:48:18Z |title=Success and problems... |author=Gold Dragon |site=Camsys |categories=Camsys}}
I have good and "bad" news for ScAIEdit III...

Well, first, the good news :) I have made some "real" tests with the AI compiler, in other words, I've tested the compiled aiscript.bin file generated by ScAIEdit III in StarCraft. After few SC crashes, in which I had to restart my whole comp(!), and thus many bug fixes, it finally works. I've started a Free For All game involving the three biggest AI scripts, the Custom ones, it hasn't crashed and comps were doing their business. So this is very good news, indeed :) After telling this to some friends over ICQ, the same question has almost immediately been asked : "Is it near beta now?". I'll answer this once and for all : No, it's not as near as you think :) There is still many things to do, like BW scripts support.

Speaking of that, I'd like to clarify something. Many think that BW scripts support means to be able to make BW units or use BW opcodes. **This is not true!** What it really means, is the ability to save scripts in the bwscript.bin file. You might think it's not a big deal, but you have to consider the two files, aiscript.bin and bwscript.bin are making references to each other, and the structure of the bwscript.bin file is slightly different. Plus, the limit size of an AI Script File is of 65535 bytes. The original aiscript.bin file has about 62050 bytes(1.05), so it really doesn't leave much place for new scripts. While you can still delete all the "useless" mission scripts(like it will be done in the default template AI script file), you can use bwscript.bin to get another 65535 bytes, and the original bwscript.bin only takes about 26458(1.05) bytes. Only needed to clarify this.

Other than that, I still have to implement references to ASC files in the AI Script Compiler, so you can actually modify the AI Script Files(pretty essential, eh? :) This is only an example of what's left, so the beta is not as near as you'd like, sorry. But still... :)

Now I guess you're waiting anxiously for the bad news ;) Well, I started making BW scripts support tonight, and I just remembered a frightening thing : the original bwscript.bin file is a real **nightmare**! There is many portions of code unused, or links to other parts of scripts, and A LOT of unknown opcodes, to give you an idea of the insanity. And what had to happen happened, ScAIEdit III crashed when compiling the BW scripts because of the obscure composition of that file.
