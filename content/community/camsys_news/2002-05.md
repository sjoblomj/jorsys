# CamSys news archive - May 2002

{{begin-newsitem |time=2002-05-26T01:32:00Z |title=MPQDraft for Windows v1.01 Maintenance Release |author=Quantam |site=Camsys |categories=Camsys |summary=MPQDraft for Windows v1.01 Maintenance Release}}

Well, I've been playing Warcraft III beta way too much lately (pretty much every free minute since I got out of school on Wednesday). But, I think I'm starting to go blind by playing it all day long. So I decided to do something nice for you guys, and work on MPQDraft.

There wasn't really a need for any major changes, but there were a few moderately large bugs that happen in very limited circumstances.

The full list of changes:
- Fixed "failed to distribute map" bug when playing SC Battle.net games
- Now works with War3 (I think; at least it doesn't give any error messages :-p)
- Now allows you to run MPQDraft on programs that don't use MPQs (so that you can use plugins)
- Made the patching error messages more descriptive

You can get it from the featured project link above.
{{end-newsitem}}
