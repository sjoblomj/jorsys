_ StarDraft on the way!- [King Arthur] - 22:33
  • Camelot Systems is pleased to announce the release of a StarCraft Utility you have all been waiting for: StarDraft. Although not finished, it is currently about 50% complete. Development is being carried out by Merlin and King Arthur. Merlin is currently unavailable to answer questions on the matter, so we ask that you direct all questions / comments / suggestions to King Arthur. StarDraft will (of course) allow you to import files into the MPQ archives that StarCraft and StarEdit use. In addition, files stored inside the MPQ archive will be editable or at least viewable from inside StarDraft much like WarDraft allowed you to do with the WAR data archives. A release date has not been set for StarDraft, but work is now heavily under way, and a release date should be available sometime soon, as well as Beta-testing information and sign-ups.

Trigger Compiler Source released.- [King Arthur] - 22:33

  • Moneran has asked me to post the following letter that he has written in response to the feedback he has recieved for the Trigger Compiler.

    I released the Starcraft Trigger Compiler a few days ago... and I've beenamazed by the feedback I've been getting. Already, I've recieved patchessolving bugs and issues with it.

    So I decided to make it official -- the Starcraft Trigger Compiler is"open-source". Go ahead, download the source at http://www.camsys.org/software/trigcomp.zip. It's written in Perl --the most popular language used for CGI-Scripts.

    It's got possibilities -- from running on a web server to turning into afull-fledged programming language with variables, while loops, notcommands -- you name it.

    If the Trigger Compiler advances enough, perhaps Blizzard will include itwith the Brood Wars Expansion.

    Have fun editing the source -- the more people who work on the triggercompiler, the greater the possibilities. If you have any suggestions,comments, or bug reports, e-mail me at hellcat5@mindless.com.

    Thanks,
    Moneran
