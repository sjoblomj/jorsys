3/27/98
  • Well, apparently a few things didn't get uploaded the other day like I thought... WarAdd is now up (the link was broken before), and you can now check out what it's good for, along with screen shots and product descriptions for all of the software that we currently have to offer here,the new software page that didn't get uploaded. :)
  • King Arthur has nearly finished with the Save code, and the new BETA should be available sometime late tomorrow evening, if everything goes well. Certain sections may not save correctly (like the GFX section), but this problem should be solved soon.
  • Well, as most of you probably know by now, StarCraft has gone Gold, and as such, the limelight that WarCraft has enjoyed for the past several years will now be very dim indeed. However, I will continue to create new versions of SPUD Farmer until I'm satisfied with the final product, and to supplythe current TC authors (who are still working quite dilligently) with another tool that will be at their disposal.
  • Since I've recieved no notification of any bugs in the current BETA's code, I'm going to assume that it's bug-free, for now, and will do no further updates to the Open code for the Beta due out tomorrow. Tomorrow's Beta will probably remain in Beta version for about a week, and then go into full releasewhen I feel that it has been tested thoroughly enough.

3/25/98
  • King Arthur is now working on the Save code for SPUD Farmer. It should be completed sometime this weekend most likely. Beta testers should try to finish bug-testing the current BETA by Saturday, when I expect to releaseBeta 5, which will include the Save code. Beta 6 will include a minimap representation of the actual PUD, and will support the lack of optional sections in the PUDs like the UDTA, UGRD, and ALOW sections. SPUD Farmer currentlyrequires that UGRD and UDTA sections be present in order to read the PUD properly. ALOW, however, is optional. SPUD Creation should also be completed for BETA 6, as will support for external files for the UGRD, UDTA, and ALOW sections.
  • The gfx conversion for the NEW game engine has been completed. Merlin is now working on the Map editor and Graphical User Interface. The Map editor will be included inside the game engine's interface, unlike War2's
  • Within the next few days we will be moving to: http://camelot.nilferax.com. There will be a re-directing page up for about two weeks after we move hopefully.

3/17/98
  • 3/17/98 Ok... obviously I have been on vacation this last week+... I apologize for not giving you guys advance notice, but it couldn't be helped. SPUD Farmer 2.0 should be available for BETA testing sometime by the end of the week (I have friday off to work on it. :) so contact me if you want to help out...An important note: the beta version will NOT have the save code implimented (on purpose - it's not quite finished yet), but as the open code is all working ok for me, the save code shouldn't be too much more complicated (I hope)

  • 3/03/98 Unit Data editor for SPUD Farmer finished. GFX editor almost done, and will be followed by the Upgrade and Restriction editors.
