New program for ya... - - 21:02 EST
  • Well, I've decided to go ahead and release my program which allows square terrain in StarEdit; dubbed ISOM. It's a very simple program, though it can be put to very good use once we found out more about what we're dealing with. Essentially the key lies in the mysterious ISOM section of a Starcraft map. This program will fill the section with a value you specify, so you can use some of the strange effects in StarEdit. Nossirahdrof and I have made little progress in finding any pattern in this section, but I have included the little work we have documented in the zip. I've got the source code all zipped up and ready to go, but, quite frankly it isn't my best work, and I'm not sure whether many people could gather much from it. If people show that they want the source code, then I'll release it.

    And this brings me to another point. I still remember the trouble I caused in my original release of SDTutor, and I've tried my best to avoid the problem in this program... Now I am *almost* positive that people won't run in to the same problem as last time, but seeing as I don't have an effective way to test this, I really can't be so sure. So, if it asks for VCL35x.bpl or whatever the hell it's called, just download the SDTutor runtime files for now, and let me know so that I know I'm wrong again :).

    Also, if you can run ISOM, and you find some magical value that does something cool, or you think you have some information on ISOM's format and why it does what it does, EMail me with some info about it, so we can find out/document more of it's effects.

    Oh yeah, for those of you wondering, this is the program that will allow perfectly square terrain in StarEdit...
    Anyway, Enjoy!

Incredible News - - 23:13 EST
  • Camelot Systems is extremely proud and honored to announce that due to the fantastic public response to our software, specifically StarDraft and Arsenal II, Blizzard Entertainment will be borrowing the services of both Andy Bond (King Arthur) and Cameron Buschardt (Merlin).
