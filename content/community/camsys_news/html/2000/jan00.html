ICEKramerBoy @ 17:15 EST

Well, since none of you are complaining to me about bug reports/requesting new features, I'll assume that this ICE version satisfied everyone's needs pretty well. That being said, I think I'll officially make the existing build the final version of ICE in its current form.

Don't fret though; I haven't abandoned the project. In fact, I'm doing just the opposite. I've begun work on a brand new, completely rebuilt ICE. New forum possibilityDark Knight @ 17:53 EST

I found recently a new forum script on the web, UltraBoard. I immediately liked it, for its good design, its wide flexibility and offers lots of options. Best of all, it's FREE! :)

Some may like it, some may dislike it... That's why we won't force the forum change, and offer you the possibility to choose between the old one, which is still active, and the new one, which currently only have The Round Table board, for test purposes. Feel free to register on it and try different options, so you can make a good decision about it. Please keep your same nick if you register :)

I've modified the script a bit in order to improve the layout, and I'm also currently improving it so it'll hopefully support auto-login feature via cookies as an option, and some other little things... Personally I like that script a lot, for being free and offer so much features. Please tell whether you like or dislike the new board, via the old forum, the new one or via e-mail. If you dislike it, please tell what are the reasons leading you to this, so I can possibly improve the board which would maybe satisfy you :)

Have fun! :) I'll post later about the final "results"...

Monday, January 03, 2000
I'm still alive...KramerBoy @ 19:56 EST

... Though I can't really say I'm doing well, as far as CS is concerned. I've been suffering through a few major hindrances with my work on ICE.

First off, my job has been getting in the way a lot more than I had anticipated. My schedule this week *very* busy. Not to mention the fact that most of my energy as well as my motivation has been drained after working such long days. Hopefully as I become more used to the workload, I'll get back in to the swing of things though.

And the other problem? ICE won't compile correctly on my new computer. I haven't the slightest idea why either. So I'm to using my old one for the rest of this project. The build time is nearly unbearable anymore, but at least I have it working on one computer.

With any luck, I'll be able to get the final set of features added in for the first release version sometime soon, but only time will tell.
