That is only because you did not replace the axe sound effect. I don't see why you would want to change that though. Especially being as this would affect all the trolls as well.  
  
Anyway, you have brought up a point that seems to be a weakness in War2 editing right now. Everyone is working on graphics, now that Rhino is widely known.  
  
Maybe some of you need to get aquainted with a utility called "goldwave." I played around with it a bit a few months ago, and it did some pretty impressive things with wav files. It works with more types of sound files than any other utility of this type I have seen.
