# sfxdata.dat Format

sfxdata.dat lists every sound effect the game can play by number: unit speech, weapon and spell sounds, explosions, advisor messages and interface sounds (see Appendix: Sounds list). Other data refers to sounds by these numbers, for example the sound fields of units.dat and the sound commands of the animation scripts. Each entry gives the WAV file, a priority, flags, a length adjustment for talking portraits and a minimum volume.

The file is arr\sfxdata.dat in the game's MPQ archives. It has 1144 entries, one for each sound, and is 10296 bytes long. It is stored field by field, not entry by entry: first the Sound File of all 1144 sounds, then the Priority of all 1144, and so on, with nothing in between. The offsets below count from the start of the file.

The layout is the same in every version from 1.04 to 1.17, in both StarCraft and Brood War. StarCraft 1.00 to 1.03 used an older layout with 968 sounds (8712 bytes). That older file is still in StarDat.mpq in later versions, but it is never loaded, because the game finds the copy in BrooDat.mpq (or patch_rt.mpq) first.

The game loads the file once, when the program starts. StarEdit does not use it. If the file is longer than the layout, the game stops with a file error. A shorter file loads without an error if it ends exactly where a field ends; the missing fields then keep whatever they held before. Out-of-range values are not rejected: the game then reads whatever follows the table that the value points into.

The game plays sounds on 8 channels. When all of them are busy, Priority and the flags decide whether a new sound replaces a playing one or is dropped.

## Priority
{{begin-formattable}}
  {{formathexlbl |label=Offset |value=0x11E0}}
  {{formatlbl |label=Length |value=1144 bytes (1 byte / Sound)}}
  {{formatlbl |label=Description |value=Only matters when all 8 channels are busy. The new sound then stops the playing sound with the lowest priority that is strictly lower than its own; sounds with flag 0x20 are never stopped this way.   {{formatlbl |label=Values |value=Integer value between 0 and 255. Shipped: 0 for mining and repair sounds, 1 for most, 2 for deaths, explosions, advisor messages and errors, 3 for the transmission sound.}}
{{end-formattable}}

## Portrait Length Adjust
{{begin-formattable}}
  {{formathexlbl |label=Offset |value=0x1AD0}}
  {{formatlbl |label=Length |value=2288 bytes (2 bytes / Sound)}}
  {{formatlbl |label=Description |value=Milliseconds added to (or, being signed, taken from) how long a unit's portrait talks when this sound is its response. The portrait talks for the sound's length rounded down to whole seconds plus this value; if the sound is not loaded yet, the adjustment is skipped. Only sounds 5 and 6 have a value other than 0, and they are never used for talking.}}
  {{formatlbl |label=Values |value=Integer value between −32768 and 32767.}}
{{end-formattable}}

## Minimum Volume
{{begin-formattable}}
  {{formathexlbl |label=Offset |value=0x23C0}}
  {{formatlbl |label=Length |value=1144 bytes (1 byte / Sound)}}
  {{formatlbl |label=Description |value=The lowest volume the sound is played at, however far away it happens, on the game's scale of 0 to 99. Sounds at a map position fade from 99 at the screen edge to 0 about 512 pixels away, and sounds quieter than 11 are not played, so values of 10 and below make no difference. Values above 99 can read past the game's volume table. Shipped: 0 for most; 10 to 50 for explosions; 100 for "out of gas".}}
  {{formatlbl |label=Values |value=Integer value between 0 and 99.}}
{{end-formattable}}
